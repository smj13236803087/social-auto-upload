# 发小红书待发（iPhone 快捷指令）

电脑会把最新一条放到 iCloud：

`文件 → iCloud 云盘 → sau-xhs-待发 → 最新待发`

里面有：

- `*.mp4`（视频）
- `一键粘贴.txt`（正文+话题，给剪贴板）
- `标题.txt`（标题，通知里提醒你）

## 建快捷指令（只需一次）

1. iPhone 打开 **快捷指令** → 右上角 **+**
2. 名称改成：**发小红书待发**
3. 按顺序添加动作：

### ① 存视频到相册

- 添加 **获取文件夹内容**
- 文件夹选：`iCloud 云盘 / sau-xhs-待发 / 最新待发`
- 打开「包含所有子文件夹」可关
- 添加 **含有**（过滤文件）：类型选 **视频**，或文件扩展名 `mp4`
- 添加 **存储到照片图库**（输入接上一步的视频）

### ② 文案进剪贴板

- 再添加 **获取文件夹内容**（同一 `最新待发` 文件夹）
- 添加 **含有**：文件名包含 `一键粘贴`
- 添加 **获取文件**（若已是文件可跳过）→ **获取文本**
- 添加 **拷贝到剪贴板**

### ③ 提醒标题 + 打开小红书

- 再获取 `最新待发` 里文件名含 `标题` 的文件 → **获取文本**
- 添加 **显示通知**：标题写「小红书标题」，正文用上一步文本
- 添加 **打开 App** → 选 **小红书**

4. 右上角完成 → 点快捷指令底部 **分享** / 详情 → **加到主屏幕**

## 以后每天怎么发

1. 等电脑下好（或你看到 `最新待发` 已更新）
2. 主屏幕点 **发小红书待发**
3. 进小红书发视频：选相册刚存入的那条
4. 标题照通知里填；正文长按 **粘贴**
5. 发布

## 注意

- 第一次运行若问权限：相册、文件、通知都允许
- 若提示找不到文件夹：先打开「文件」进一次 `sau-xhs-待发/最新待发`，再跑快捷指令
- `最新待发` 每次会被新视频覆盖；历史在带日期的文件夹里
